Esta é uma versão condensada do nosso [Guia de Instalação Local](/docs/local/)

## Passo 1. Baixe o Projeto [#step-1-download-the-project]

### Download Manual [#manual-download]

1. **Vá para a Página do Projeto**: Visite [https://github.com/LibreChat-AI/LibreChat](https://github.com/LibreChat-AI/LibreChat).

2. **Baixe o arquivo ZIP**: Clique no botão verde "Code" e, em seguida, clique em "Download ZIP."

3. **Extraia o arquivo ZIP**: Localize o arquivo ZIP baixado, clique com o botão direito e selecione "Extrair tudo...".

### Usando o Git [#using-git]

Execute o seguinte comando [git](https://git-scm.com/) no seu terminal, a partir do diretório pai desejado:

```bash
git clone https://github.com/LibreChat-AI/LibreChat.git
```

## Passo 2. Instalar o Docker [#step-2-install-docker]

1. **Download**: Vá para a [Docker Desktop Download Page](https://www.docker.com/products/docker-desktop) e baixe o Docker Desktop.
2. **Instalação**: Abra o instalador e siga as instruções.
3. **Executar**: Abra o Docker Desktop para garantir que ele esteja em execução.

**Notas:**
- O Docker Desktop é recomendado para a maioria dos usuários. Se você está procurando uma configuração avançada de docker/container, especialmente para uma instalação em servidor remoto, consulte nosso [Guia de Implantação Docker no Ubuntu](/docs/remote/docker_linux).
- Você pode precisar reiniciar seu computador após a instalação.

## Passo 3. Executar o App [#step-3-run-the-app]

1. **Navegue até o Diretório do Projeto**: Abra um terminal na pasta `LibreChat` que você clonou ou extraiu no Passo 1. Se você usou o Git:

   ```bash
   cd LibreChat
   ```

2. **Crie o arquivo .env**: Copie `.env.example` para um novo arquivo chamado `.env`:

   ```bash
   cp .env.example .env
   ```

   No Windows, use `copy .env.example .env` se o comando `cp` não estiver disponível.

   Os valores padrão funcionam prontos para uso em uma configuração local básica. Para uma configuração detalhada do ambiente, consulte o [Guia de Configuração do arquivo .env](/docs/configuration/dotenv).

3. **Inicie a Aplicação**: Certifique-se de que o Docker Desktop está em execução e, em seguida, execute:

   ```bash
   docker compose up -d
   ```

   A primeira inicialização baixa as imagens do Docker e pode levar alguns minutos. As inicializações seguintes são bem mais rápidas. Se um contêiner parar logo após iniciar, consulte a [seção de solução de problemas do guia do Docker](/docs/local/docker#troubleshooting).

## Passo 4. Comece a conversar [#step-4-start-chatting]

O LibreChat está em execução, mas precisa de uma conta e de um modelo antes que possa responder a qualquer coisa:

1. **Abra** [http://localhost:3080](http://localhost:3080) no seu navegador.
2. **Registre** uma conta na página de login.
3. **Adicione uma chave de API** para o provedor que você deseja usar.

Siga [Seu Primeiro Chat](/docs/quick_start/first_chat) para ver estes passos em detalhes, incluindo o que fazer quando nenhum modelo responder.
