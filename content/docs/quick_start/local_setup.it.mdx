Questa è una versione condensata della nostra [Guida all'installazione locale](/docs/local/)

## Passaggio 1. Scarica il progetto [#step-1-download-the-project]

### Download manuale [#manual-download]

1. **Vai alla pagina del progetto**: Visita [https://github.com/LibreChat-AI/LibreChat](https://github.com/LibreChat-AI/LibreChat).

2. **Scarica il file ZIP**: Fai clic sul pulsante verde "Code", quindi fai clic su "Download ZIP."

3. **Estrai il file ZIP**: Individua il file ZIP scaricato, fai clic con il tasto destro e seleziona "Estrai tutto...".

### Utilizzo di Git [#using-git]

Esegui il seguente comando [git](https://git-scm.com/) nel tuo terminale, dalla directory padre desiderata:

```bash
git clone https://github.com/LibreChat-AI/LibreChat.git
```

## Passaggio 2. Installare Docker [#step-2-install-docker]

1. **Download**: Vai alla [Pagina di download di Docker Desktop](https://www.docker.com/products/docker-desktop) e scarica Docker Desktop.
2. **Install**: Apri il programma di installazione e segui le istruzioni.
3. **Esecuzione**: Apri Docker Desktop per assicurarti che sia in esecuzione.

**Note:**
- Docker Desktop è consigliato per la maggior parte degli utenti. Se stai cercando una configurazione avanzata di docker/container, specialmente per un'installazione su server remoto, consulta la nostra [Guida all'implementazione di Docker su Ubuntu](/docs/remote/docker_linux).
- Potrebbe essere necessario riavviare il computer dopo l'installazione.

## Passaggio 3. Esegui l'App [#step-3-run-the-app]

1. **Accedi alla directory del progetto**: apri un terminale nella cartella `LibreChat` che hai clonato o estratto nel Passaggio 1. Se hai usato Git:

   ```bash
   cd LibreChat
   ```

2. **Crea il file .env**: copia `.env.example` in un nuovo file denominato `.env`:

   ```bash
   cp .env.example .env
   ```

   Su Windows, usa `copy .env.example .env` se `cp` non è disponibile

   I valori predefiniti funzionano subito per una configurazione locale di base. Per una configurazione approfondita dell'ambiente, consulta la [Guida alla configurazione del file .env](/docs/configuration/dotenv).

3. **Avvia l'applicazione**: assicurati che Docker Desktop sia in esecuzione, quindi esegui:

   ```bash
   docker compose up -d
   ```

   Il primo avvio scarica le immagini Docker e può richiedere alcuni minuti. Gli avvii successivi sono molto più rapidi. Se un container si arresta subito dopo l'avvio, consulta la [sezione di risoluzione dei problemi della guida Docker](/docs/local/docker#troubleshooting).

## Passaggio 4. Inizia a chattare [#step-4-start-chatting]

LibreChat è ora in esecuzione, ma necessita di un account e di un modello prima di poter rispondere a qualsiasi cosa:

1. **Apri** [http://localhost:3080](http://localhost:3080) nel tuo browser.
2. **Registra** un account nella pagina di login.
3. **Aggiungi una API key** per il provider che desideri utilizzare.

Segui [La tua prima chat](/docs/quick_start/first_chat) per questi passaggi in dettaglio, incluso cosa fare quando nessun modello risponde.
