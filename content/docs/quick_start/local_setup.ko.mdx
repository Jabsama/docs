이 문서는 [Local Installation Guide](/docs/local/)의 요약 버전입니다.

## 1단계. 프로젝트 다운로드 [#step-1-download-the-project]

### 수동 다운로드 [#manual-download]

1. **프로젝트 페이지로 이동**: [https://github.com/LibreChat-AI/LibreChat](https://github.com/LibreChat-AI/LibreChat)를 방문하세요.

2. **ZIP 파일 다운로드**: 녹색 "Code" 버튼을 클릭한 다음, "Download ZIP"을 클릭하세요.

3. **ZIP 파일 압축 풀기**: 다운로드한 ZIP 파일을 찾아 마우스 오른쪽 버튼으로 클릭한 다음 "모두 압축 풀기..."를 선택합니다.

### Git 사용하기 [#using-git]

원하는 상위 디렉토리에서 터미널에 다음 [git](https://git-scm.com/) 명령어를 실행하세요:

```bash
git clone https://github.com/LibreChat-AI/LibreChat.git
```

## 2단계. Docker 설치 [#step-2-install-docker]

1. **다운로드**: [Docker Desktop 다운로드 페이지](https://www.docker.com/products/docker-desktop)로 이동하여 Docker Desktop을 다운로드하세요.
2. **설치**: 설치 프로그램을 열고 지침을 따르세요.
3. **실행(Run)**: Docker Desktop을 열어 실행 중인지 확인하세요.

**참고:**
- 대부분의 사용자에게는 Docker Desktop을 권장합니다. 고급 docker/컨테이너 설정을 찾고 계시거나, 특히 원격 서버 설치를 원하시는 경우 [Ubuntu Docker Deployment Guide](/docs/remote/docker_linux)를 참조하세요.
- 설치 후 컴퓨터를 다시 시작해야 할 수도 있습니다.

## 3단계. 앱 실행하기 [#step-3-run-the-app]

1. **프로젝트 디렉터리로 이동**: 1단계에서 클론하거나 압축을 해제한 `LibreChat` 폴더에서 터미널을 엽니다. Git을 사용했다면:

   ```bash
   cd LibreChat
   ```

2. **.env 파일 생성**: `.env.example`을 복사하여 `.env`라는 이름의 새 파일을 만드세요:

   ```bash
   cp .env.example .env
   ```

   Windows에서는 `cp`를 사용할 수 없는 경우 `copy .env.example .env`를 사용하세요.

   기본값은 기본적인 로컬 설정에서 별도의 변경 없이 바로 작동합니다. 상세한 환경 구성은 [.env 파일 구성 가이드](/docs/configuration/dotenv)를 참고하세요.

3. **애플리케이션 시작**: Docker Desktop이 실행 중인지 확인한 다음 다음 명령을 실행하세요:

   ```bash
   docker compose up -d
   ```

   첫 실행 시에는 Docker 이미지를 다운로드하므로 몇 분 정도 걸릴 수 있습니다. 이후 실행은 훨씬 빠릅니다. 컨테이너가 시작 직후 중지되는 경우에는 [Docker 가이드 문제 해결 섹션](/docs/local/docker#troubleshooting)을 참고하세요.

## 4단계. 채팅 시작하기 [#step-4-start-chatting]

LibreChat이 실행 중이지만, 답변을 하려면 계정과 모델이 필요합니다:

1. 브라우저에서 [http://localhost:3080](http://localhost:3080)을(를) **여십시오**.
2. 로그인 페이지에서 계정을 **등록(Register)**하세요.
3. 사용하려는 공급자에 대한 **API 키를 추가**하세요.

이 단계들에 대한 자세한 내용은 [Your First Chat](/docs/quick_start/first_chat)을 참조하세요. 모델이 응답하지 않을 때 수행할 작업도 포함되어 있습니다.
