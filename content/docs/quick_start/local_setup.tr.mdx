Bu, [Local Installation Guide](/docs/local/) kılavuzumuzun özetlenmiş bir versiyonudur.

## Adım 1. Projeyi İndirin [#step-1-download-the-project]

### Manuel İndirme [#manual-download]

1. **Proje Sayfasına Git**: [https://github.com/LibreChat-AI/LibreChat](https://github.com/LibreChat-AI/LibreChat) adresini ziyaret edin.

2. **ZIP Dosyasını İndirin**: Yeşil "Code" butonuna tıklayın, ardından "Download ZIP" seçeneğine tıklayın.

3. **ZIP Dosyasını Çıkartın**: İndirilen ZIP dosyasını bulun, sağ tıklayın ve "Tümünü Ayıkla..." seçeneğini seçin.

### Git Kullanımı [#using-git]

Terminalinizde, istediğiniz üst dizinden aşağıdaki [git](https://git-scm.com/) komutunu çalıştırın:

```bash
git clone https://github.com/LibreChat-AI/LibreChat.git
```

## Adım 2. Docker kurulumu [#step-2-install-docker]

1. **İndirme**: [Docker Desktop İndirme Sayfası](https://www.docker.com/products/docker-desktop) adresine gidin ve Docker Desktop'ı indirin.
2. **Kurulum**: Yükleyiciyi açın ve talimatları izleyin.
3. **Çalıştırma**: Çalıştığından emin olmak için Docker Desktop'ı açın.

**Notlar:**
- Çoğu kullanıcı için Docker Desktop önerilir. Özellikle uzak bir sunucu kurulumu için gelişmiş bir docker/konteyner kurulumu arıyorsanız, [Ubuntu Docker Deployment Guide](/docs/remote/docker_linux) bölümümüze göz atın.
- Kurulumdan sonra bilgisayarınızı yeniden başlatmanız gerekebilir.

## Adım 3. Uygulamayı Çalıştırın [#step-3-run-the-app]

1. **Proje Dizinine Gidin**: Adım 1'de klonladığınız veya çıkardığınız `LibreChat` klasöründe bir terminal açın. Git kullandıysanız:

   ```bash
   cd LibreChat
   ```

2. **.env Dosyasını Oluşturun**: `.env.example` dosyasını `.env` adlı yeni bir dosyaya kopyalayın:

   ```bash
   cp .env.example .env
   ```

   On Windows, use `copy .env.example .env` if `cp` is not available.

   Varsayılan değerler, temel bir yerel kurulum için kutudan çıktığı gibi çalışır. Ayrıntılı ortam yapılandırması için [.env Dosyası Yapılandırma Kılavuzu](/docs/configuration/dotenv) bölümüne bakın.

3. **Uygulamayı Başlatın**: Docker Desktop'ın çalıştığından emin olun, ardından şunu çalıştırın:

   ```bash
   docker compose up -d
   ```

   İlk başlatma Docker imajlarını indirir ve birkaç dakika sürebilir. Sonraki başlatmalar çok daha hızlıdır. Bir container başlatıldıktan hemen sonra duruyorsa, [Docker kılavuzu sorun giderme bölümüne](/docs/local/docker#troubleshooting) bakın.

## Adım 4. Sohbet Etmeye Başlayın [#step-4-start-chatting]

LibreChat şu anda çalışıyor, ancak herhangi bir yanıt verebilmesi için bir hesaba ve bir modele ihtiyacı var:

1. Tarayıcınızda [http://localhost:3080](http://localhost:3080) adresini **açın**.
2. Giriş sayfasında bir hesap **oluşturun**.
3. Kullanmak istediğiniz sağlayıcı için **bir API anahtarı ekleyin**.

Bu adımların detayları ve hiçbir modelin yanıt vermemesi durumunda ne yapmanız gerektiği için [İlk Sohbetiniz](/docs/quick_start/first_chat) bölümünü takip edin.
