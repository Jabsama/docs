Đây là phiên bản rút gọn của [Hướng dẫn cài đặt cục bộ](/docs/local/) của chúng tôi

## Bước 1. Tải xuống dự án [#step-1-download-the-project]

### Tải xuống thủ công [#manual-download]

1. **Đi tới Trang Dự án**: Truy cập [https://github.com/LibreChat-AI/LibreChat](https://github.com/LibreChat-AI/LibreChat).

2. **Tải xuống tệp ZIP**: Nhấp vào nút "Code" màu xanh lá cây, sau đó nhấp vào "Download ZIP."

3. **Giải nén tệp ZIP**: Tìm tệp ZIP đã tải xuống, nhấp chuột phải và chọn "Extract All...".

### Sử dụng Git [#using-git]

Chạy lệnh [git](https://git-scm.com/) sau trong terminal của bạn, từ thư mục cha mong muốn:

```bash
git clone https://github.com/LibreChat-AI/LibreChat.git
```

## Bước 2. Cài đặt Docker [#step-2-install-docker]

1. **Tải xuống**: Truy cập [Trang tải xuống Docker Desktop](https://www.docker.com/products/docker-desktop) và tải xuống Docker Desktop.
2. **Cài đặt**: Mở trình cài đặt và làm theo các hướng dẫn.
3. **Chạy**: Mở Docker Desktop để đảm bảo ứng dụng đang chạy.

**Ghi chú:**
- Docker Desktop được khuyến nghị cho hầu hết người dùng. Nếu bạn đang tìm kiếm một thiết lập docker/container nâng cao, đặc biệt là cho việc cài đặt trên máy chủ từ xa, hãy xem [Hướng dẫn triển khai Docker trên Ubuntu](/docs/remote/docker_linux) của chúng tôi.
- Bạn có thể cần khởi động lại máy tính sau khi cài đặt.

## Bước 3. Chạy ứng dụng [#step-3-run-the-app]

1. **Điều hướng đến thư mục dự án**: Mở terminal trong thư mục `LibreChat` mà bạn đã clone hoặc giải nén ở Bước 1. Nếu bạn dùng Git:

   ```bash
   cd LibreChat
   ```

2. **Tạo tệp .env**: Sao chép `.env.example` thành một tệp mới có tên `.env`:

   ```bash
   cp .env.example .env
   ```

   Trên Windows, hãy sử dụng `copy .env.example .env` nếu `cp` không khả dụng.

   Các giá trị mặc định hoạt động ngay lập tức với thiết lập cục bộ cơ bản. Để tìm hiểu chi tiết về cấu hình môi trường, xem [Hướng dẫn cấu hình tệp .env](/docs/configuration/dotenv).

3. **Khởi động ứng dụng**: Hãy đảm bảo Docker Desktop đang chạy, sau đó chạy:

   ```bash
   docker compose up -d
   ```

   Lần khởi chạy đầu tiên sẽ tải xuống các Docker image và có thể mất vài phút. Những lần khởi động sau sẽ nhanh hơn nhiều. Nếu một container dừng ngay sau khi khởi động, hãy xem [phần khắc phục sự cố trong hướng dẫn Docker](/docs/local/docker#troubleshooting).

## Bước 4. Bắt đầu trò chuyện [#step-4-start-chatting]

LibreChat hiện đã chạy, nhưng cần có tài khoản và model trước khi có thể trả lời bất kỳ điều gì:

1. **Mở** [http://localhost:3080](http://localhost:3080) trong trình duyệt của bạn.
2. **Đăng ký** tài khoản trên trang đăng nhập.
3. **Thêm một API key** cho nhà cung cấp mà bạn muốn sử dụng.

Hãy làm theo [Your First Chat](/docs/quick_start/first_chat) để biết chi tiết các bước này, bao gồm cả những việc cần làm khi không có mô hình nào phản hồi.
