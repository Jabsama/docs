Esta es una versión condensada de nuestra [Guía de instalación local](/docs/local/)

## Paso 1. Descargar el proyecto [#step-1-download-the-project]

### Descarga manual [#manual-download]

1. **Ve a la página del proyecto**: Visita [https://github.com/LibreChat-AI/LibreChat](https://github.com/LibreChat-AI/LibreChat).

2. **Descargar el archivo ZIP**: Haz clic en el botón verde "Code" y luego en "Download ZIP."

3. **Extraer el archivo ZIP**: Localice el archivo ZIP descargado, haga clic derecho y seleccione "Extraer todo...".

### Uso de Git [#using-git]

Ejecute el siguiente comando de [git](https://git-scm.com/) en su terminal, desde el directorio principal deseado:

```bash
git clone https://github.com/LibreChat-AI/LibreChat.git
```

## Paso 2. Instalar Docker [#step-2-install-docker]

1. **Descarga**: Ve a la [Docker Desktop Download Page](https://www.docker.com/products/docker-desktop) y descarga Docker Desktop.
2. **Instalación**: Abra el instalador y siga las instrucciones.
3. **Ejecutar**: Abra Docker Desktop para asegurarse de que se esté ejecutando.

**Notas:**
- Docker Desktop es recomendado para la mayoría de los usuarios. Si buscas una configuración avanzada de docker/contenedor, especialmente para una instalación en servidor remoto, consulta nuestra [Guía de despliegue de Docker en Ubuntu](/docs/remote/docker_linux).
- Es posible que necesites reiniciar tu computadora después de la instalación.

## Paso 3. Ejecutar la aplicación [#step-3-run-the-app]

1. **Navega al directorio del proyecto**: Abre una terminal en la carpeta `LibreChat` que clonaste o extrajiste en el Paso 1. Si usaste Git:

   ```bash
   cd LibreChat
   ```

2. **Crea el archivo .env**: Copia `.env.example` en un nuevo archivo llamado `.env`:

   ```bash
   cp .env.example .env
   ```

   En Windows, utiliza `copy .env.example .env` si `cp` no está disponible.

   Los valores predeterminados funcionan de inmediato para una configuración local básica. Para una configuración detallada del entorno, consulta la [Guía de configuración del archivo .env](/docs/configuration/dotenv).

3. **Iniciar la aplicación**: Asegúrate de que Docker Desktop esté en ejecución y luego ejecuta:

   ```bash
   docker compose up -d
   ```

   El primer inicio descarga las imágenes de Docker y puede tardar unos minutos. Los inicios posteriores son mucho más rápidos. Si un contenedor se detiene justo después de iniciarse, consulta la [sección de solución de problemas de la guía de Docker](/docs/local/docker#troubleshooting).

## Paso 4. Empieza a chatear [#step-4-start-chatting]

LibreChat ya se está ejecutando, pero necesita una cuenta y un modelo antes de poder responder a cualquier cosa:

1. **Abra** [http://localhost:3080](http://localhost:3080) en su navegador.
2. **Regístrese** para obtener una cuenta en la página de inicio de sesión.
3. **Agregue una API key** para el proveedor que desea utilizar.

Sigue [Tu primer chat](/docs/quick_start/first_chat) para ver estos pasos en detalle, incluyendo qué hacer cuando ningún modelo responde.
