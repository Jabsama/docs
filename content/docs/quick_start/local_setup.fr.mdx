Ceci est une version condensée de notre [Guide d'installation locale](/docs/local/)

## Étape 1. Télécharger le projet [#step-1-download-the-project]

### Téléchargement manuel [#manual-download]

1. **Accédez à la page du projet** : Visitez [https://github.com/LibreChat-AI/LibreChat](https://github.com/LibreChat-AI/LibreChat).

2. **Télécharger le fichier ZIP** : Cliquez sur le bouton vert "Code", puis cliquez sur "Download ZIP."

3. **Extraire le fichier ZIP** : Localisez le fichier ZIP téléchargé, faites un clic droit et sélectionnez "Extraire tout...".

### Utilisation de Git [#using-git]

Exécutez la commande [git](https://git-scm.com/) suivante dans votre terminal, depuis le répertoire parent souhaité :

```bash
git clone https://github.com/LibreChat-AI/LibreChat.git
```

## Étape 2. Installer Docker [#step-2-install-docker]

1. **Téléchargement** : Allez sur la [page de téléchargement de Docker Desktop](https://www.docker.com/products/docker-desktop) et téléchargez Docker Desktop.
2. **Installation** : Ouvrez l'installateur et suivez les instructions.
3. **Exécution** : Ouvrez Docker Desktop pour vous assurer qu'il est en cours d'exécution.

**Notes :**
- Docker Desktop est recommandé pour la plupart des utilisateurs. Si vous recherchez une configuration docker/conteneur avancée, notamment pour une installation sur serveur distant, consultez notre [Guide de déploiement Docker sur Ubuntu](/docs/remote/docker_linux).
- Il peut être nécessaire de redémarrer votre ordinateur après l'installation.

## Étape 3. Exécuter l'application [#step-3-run-the-app]

1. **Naviguez jusqu'au répertoire du projet** : Ouvrez un terminal dans le dossier `LibreChat` que vous avez cloné ou extrait à l'étape 1. Si vous avez utilisé Git :

   ```bash
   cd LibreChat
   ```

2. **Créer le fichier .env** : copiez `.env.example` dans un nouveau fichier nommé `.env` :

   ```bash
   cp .env.example .env
   ```

   On Windows, use `copy .env.example .env` if `cp` is not available.

   Les valeurs par défaut fonctionnent directement pour une configuration locale de base. Pour une configuration approfondie de l'environnement, consultez le [guide de configuration du fichier .env](/docs/configuration/dotenv).

3. **Démarrer l'application** : Assurez-vous que Docker Desktop est en cours d'exécution, puis exécutez :

   ```bash
   docker compose up -d
   ```

   Le premier lancement télécharge les images Docker et peut prendre quelques minutes. Les démarrages suivants sont beaucoup plus rapides. Si un conteneur s'arrête juste après son démarrage, consultez la [section de dépannage du guide Docker](/docs/local/docker#troubleshooting).

## Étape 4. Commencer à discuter [#step-4-start-chatting]

LibreChat est maintenant en cours d'exécution, mais il nécessite un compte et un modèle avant de pouvoir répondre à quoi que ce soit :

1. **Ouvrez** [http://localhost:3080](http://localhost:3080) dans votre navigateur.
2. **Enregistrez** un compte sur la page de connexion.
3. **Ajoutez une clé API** pour le fournisseur que vous souhaitez utiliser.

Suivez [Votre premier chat](/docs/quick_start/first_chat) pour obtenir ces étapes en détail, y compris la marche à suivre lorsqu'aucun modèle ne répond.
