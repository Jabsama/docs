## ステップ 1. プロジェクトのダウンロード [#step-1-download-the-project]

### 手動ダウンロード [#manual-download]

1. **プロジェクトページへ移動**: [https://github.com/LibreChat-AI/LibreChat](https://github.com/LibreChat-AI/LibreChat) にアクセスしてください。

2. **ZIPファイルをダウンロード**: 緑色の「Code」ボタンをクリックし、「Download ZIP」をクリックします。

3. **ZIPファイルを展開する**: ダウンロードしたZIPファイルを見つけ、右クリックして「すべて展開...」を選択します。

### Gitの使用 [#using-git]

ターミナルで、目的の親ディレクトリから以下の [git](https://git-scm.com/) コマンドを実行してください：

```bash
git clone https://github.com/LibreChat-AI/LibreChat.git
```

## ステップ 2. Docker をインストールする [#step-2-install-docker]

1. **ダウンロード**: [Docker Desktop ダウンロードページ](https://www.docker.com/products/docker-desktop) にアクセスし、Docker Desktop をダウンロードしてください。
2. **インストール**: インストーラーを開き、指示に従ってください。
3. **実行**: Docker Desktop を開き、実行中であることを確認します。

**注記:**
- ほとんどのユーザーには Docker Desktop が推奨されます。高度な Docker/コンテナ設定、特にリモートサーバーへのインストールをお探しの場合は、[Ubuntu Docker Deployment Guide](/docs/remote/docker_linux) を参照してください。
- インストール後、コンピュータの再起動が必要になる場合があります。

## ステップ 3. アプリの実行 [#step-3-run-the-app]

1. **プロジェクトディレクトリに移動する**: Step 1 でクローンまたは展開した `LibreChat` フォルダでターミナルを開きます。Git を使用した場合は次のとおりです:

   ```bash
   cd LibreChat
   ```

2. **.env ファイルを作成する**: `.env.example` を `.env` という名前の新しいファイルにコピーします。

   ```bash
   cp .env.example .env
   ```

   On Windows, use `copy .env.example .env` if `cp` is not available.

   デフォルト値は、基本的なローカル環境であればそのまま動作します。環境設定の詳細については、[.env ファイル設定ガイド](/docs/configuration/dotenv)を参照してください。

3. **アプリケーションを起動する**: Docker Desktop が起動していることを確認してから、次を実行します:

   ```bash
   docker compose up -d
   ```

   初回起動時はDockerイメージのダウンロードが行われるため、数分かかることがあります。2回目以降の起動ははるかに速くなります。コンテナが起動直後に停止する場合は、[Dockerガイドのトラブルシューティングセクション](/docs/local/docker#troubleshooting)を参照してください。

## ステップ 4. チャットを開始する [#step-4-start-chatting]

LibreChatは現在実行中ですが、回答を行うにはアカウントとモデルが必要です：

1. ブラウザで [http://localhost:3080](http://localhost:3080) を**開いて**ください。
2. ログインページでアカウントを**登録**します。
3. **APIキーを追加**します（使用したいプロバイダーのもの）。

これらの手順の詳細については、モデルが回答しない場合の対処法を含め、[Your First Chat](/docs/quick_start/first_chat) を参照してください。
