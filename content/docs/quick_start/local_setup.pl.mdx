To jest skrócona wersja naszego [Przewodnika instalacji lokalnej](/docs/local/)

## Krok 1. Pobierz projekt [#step-1-download-the-project]

### Ręczne pobieranie [#manual-download]

1. **Przejdź do strony projektu**: Odwiedź [https://github.com/LibreChat-AI/LibreChat](https://github.com/LibreChat-AI/LibreChat).

2. **Pobierz plik ZIP**: Kliknij zielony przycisk "Code", a następnie kliknij "Download ZIP."

3. **Wypakuj plik ZIP**: Znajdź pobrany plik ZIP, kliknij go prawym przyciskiem myszy i wybierz „Wyodrębnij wszystko...”.

### Korzystanie z Git [#using-git]

Uruchom następujące polecenie [git](https://git-scm.com/) w swoim terminalu, z poziomu wybranego katalogu nadrzędnego:

```bash
git clone https://github.com/LibreChat-AI/LibreChat.git
```

## Krok 2. Zainstaluj Docker [#step-2-install-docker]

1. **Pobieranie**: Przejdź do [strony pobierania Docker Desktop](https://www.docker.com/products/docker-desktop) i pobierz Docker Desktop.
2. **Instalacja**: Otwórz instalator i postępuj zgodnie z instrukcjami.
3. **Uruchomienie**: Otwórz Docker Desktop, aby upewnić się, że działa.

**Uwagi:**
- Docker Desktop jest zalecany dla większości użytkowników. Jeśli szukasz zaawansowanej konfiguracji docker/kontenerów, zwłaszcza w przypadku instalacji na zdalnym serwerze, zapoznaj się z naszym [Przewodnikiem wdrażania Docker na Ubuntu](/docs/remote/docker_linux).
- Po instalacji może być konieczne ponowne uruchomienie komputera.

## Krok 3. Uruchom aplikację [#step-3-run-the-app]

1. **Przejdź do katalogu projektu**: Otwórz terminal w folderze `LibreChat`, który sklonowałeś lub rozpakowałeś w kroku 1. Jeśli używasz Gita:

   ```bash
   cd LibreChat
   ```

2. **Utwórz plik .env**: Skopiuj `.env.example` do nowego pliku o nazwie `.env`:

   ```bash
   cp .env.example .env
   ```

   W systemie Windows użyj `copy .env.example .env`, jeśli polecenie `cp` nie jest dostępne.

   Wartości domyślne działają od razu po uruchomieniu w podstawowej konfiguracji lokalnej. Szczegółową konfigurację środowiska znajdziesz w [przewodniku konfiguracji pliku .env](/docs/configuration/dotenv).

3. **Uruchom aplikację**: Upewnij się, że Docker Desktop jest uruchomiony, a następnie wykonaj:

   ```bash
   docker compose up -d
   ```

   Pierwsze uruchomienie pobiera obrazy Docker i może potrwać kilka minut. Kolejne starty są znacznie szybsze. Jeśli kontener zatrzyma się zaraz po uruchomieniu, zobacz [sekcję rozwiązywania problemów w przewodniku Docker](/docs/local/docker#troubleshooting).

## Krok 4. Rozpocznij czat [#step-4-start-chatting]

LibreChat jest teraz uruchomiony, ale wymaga konta i modelu, zanim będzie mógł na cokolwiek odpowiedzieć:

1. **Otwórz** [http://localhost:3080](http://localhost:3080) w swojej przeglądarce.
2. **Zarejestruj** konto na stronie logowania.
3. **Dodaj klucz API** dla dostawcy, którego chcesz użyć.

Postępuj zgodnie z [Twój pierwszy czat](/docs/quick_start/first_chat), aby uzyskać szczegółowe informacje na temat tych kroków, w tym co zrobić, gdy żaden model nie odpowiada.
