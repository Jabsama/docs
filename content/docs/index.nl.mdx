<Callout type="info" title="Wil je gewoon beginnen met chatten?">

Probeer LibreChat nu direct op de gratis publieke demo van het project op [chat.librechat.ai](https://chat.librechat.ai): maak daar een account aan en start een gesprek. De demo is uitsluitend bedoeld voor evaluatiedoeleinden en is daarom niet de plek voor privégegevens of zaken die u moet bewaren ([voorwaarden](/demo/terms), [privacy](/demo/privacy)).

Voor een eigen instantie installeer je LibreChat met de [Quick Start](/docs/quick_start) (ongeveer vijf minuten met Docker), volg daarna [Your First Chat](/docs/quick_start/first_chat) om je account aan te maken, een model API key toe te voegen en je eerste bericht te versturen.

</Callout>

<Callout type="info" title="Op zoek naar een desktop-installer?">

LibreChat is een zelf gehoste webtoepassing, geen native desktopapp voor Windows, macOS of Linux. Gebruik op Windows [Docker Desktop](/docs/local/docker) voor de eenvoudigste lokale installatie. Gebruik op macOS ook [Docker Desktop](/docs/local/docker); lees op Macs met Apple Silicon (M-serie) eerst de MongoDB-opmerking voor Apple Silicon in de vereisten van de Docker-handleiding voordat je begint. Voor Linux-desktops of -servers gebruik je [Docker](/docs/local/docker), [npm](/docs/local/npm), of een [handleiding voor externe hosting](/docs/remote).

</Callout>
