<Callout type="info" title="¿Solo quieres empezar a chatear?">

Prueba LibreChat ahora mismo en la demostración pública gratuita del proyecto en [chat.librechat.ai](https://chat.librechat.ai): crea una cuenta allí y comienza una conversación. La demostración es solo para fines de evaluación, por lo que no es el lugar para datos privados o cualquier cosa que necesites conservar ([términos](/demo/terms), [privacidad](/demo/privacy)).

Para una instancia propia, instala LibreChat con el [Quick Start](/docs/quick_start) (aproximadamente cinco minutos con Docker), luego sigue [Your First Chat](/docs/quick_start/first_chat) para crear tu cuenta, añadir una API key de modelo y enviar tu primer mensaje.

</Callout>

<Callout type="info" title="¿Buscas un instalador de escritorio?">

LibreChat es una aplicación web autoalojada, no una aplicación de escritorio nativa para Windows, macOS o Linux. En Windows, usa [Docker Desktop](/docs/local/docker) para la configuración local más sencilla. En macOS, también usa [Docker Desktop](/docs/local/docker); en Macs con Apple Silicon (serie M), lee la nota de MongoDB para Apple Silicon en los requisitos previos de la guía de Docker antes de empezar. Para escritorios o servidores Linux, usa [Docker](/docs/local/docker), [npm](/docs/local/npm) o una [guía de alojamiento remoto](/docs/remote).

</Callout>
