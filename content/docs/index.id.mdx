<Callout type="info" title="Ingin langsung mulai mengobrol?">

Coba LibreChat sekarang juga di demo publik gratis proyek ini di [chat.librechat.ai](https://chat.librechat.ai): buat akun di sana dan mulailah percakapan. Demo ini hanya untuk evaluasi, jadi ini bukan tempat untuk data pribadi atau apa pun yang perlu Anda simpan ([ketentuan](/demo/terms), [privasi](/demo/privacy)).

Untuk instans Anda sendiri, instal LibreChat dengan [Quick Start](/docs/quick_start) (sekitar lima menit dengan Docker), lalu ikuti [Your First Chat](/docs/quick_start/first_chat) untuk membuat akun Anda, menambahkan API key model, dan mengirim pesan pertama Anda.

</Callout>

<Callout type="info" title="Mencari penginstal desktop?">

LibreChat adalah aplikasi web yang di-*self-host*, bukan aplikasi desktop native untuk Windows, macOS, atau Linux. Di Windows, gunakan [Docker Desktop](/docs/local/docker) untuk penyiapan lokal yang paling sederhana. Di macOS, gunakan juga [Docker Desktop](/docs/local/docker); pada Mac Apple Silicon (seri M), baca catatan MongoDB Apple Silicon di prasyarat panduan Docker sebelum memulai. Untuk desktop atau server Linux, gunakan [Docker](/docs/local/docker), [npm](/docs/local/npm), atau [panduan hosting jarak jauh](/docs/remote).

</Callout>
